# Noodle Theory Landing Page

## Overview

Noodle Theory is a fictional ramen shop that recently gained local popularity. This project is a fast 60-minute build to create, deploy, and launch a polished restaurant landing page that looks professional, works well on mobile, and gives customers the key information they need: menu, location, hours, phone number, and an order call-to-action.

## Goals

1. Build a complete restaurant landing page with all required sections within the deadline.
2. Make the page look like a real local ramen business with strong visual polish.
3. Ensure the layout is mobile-responsive and easy to use on small screens.
4. Deploy the finished website to Vercel and provide a live URL.
5. Complete the required submission items: live URL, mobile screenshot, and short reflection.

## Core User Flow

1. A visitor opens the Noodle Theory landing page.
2. The visitor sees a strong hero section with a clear ramen-shop brand message.
3. The visitor scrolls to view menu items, prices, and descriptions.
4. The visitor checks the shop location and map-style layout.
5. The visitor checks hours and phone number.
6. The visitor clicks the Order Now button or uses the contact information.

## Features

### Hero Section

- High-vibe headline for the ramen shop.
- Short supporting text explaining the restaurant experience.
- Strong visual layout using warm ramen-inspired design.
- Primary Order Now button.
- Optional secondary link to menu section.

### Menu Section

- Minimum of 8 realistic menu items.
- Each item includes name, description, and price.
- Items should feel believable for a modern ramen shop.
- Menu cards must be readable on mobile.

### Location Section

- Fictional restaurant address.
- Map-style visual layout or static map placeholder.
- Clear nearby/location text to make the business feel real.

### Contact and CTA Section

- Operating hours.
- Phone number.
- Order Now button.
- Final conversion-focused message.

### Deployment and Submission

- GitHub repository with feature branch `feat/landing-page`.
- Pull Request created and documented before merge.
- Vercel deployment.
- Mobile screenshot.
- 3–5 sentence write-up.

## Scope

### In Scope

- Single-page restaurant landing page.
- Static content only.
- Responsive layout for mobile, tablet, and desktop.
- Next.js 16, React, TypeScript, Tailwind CSS, and shadcn/ui.
- Base component style and Sera-inspired visual direction.
- Vercel deployment.
- GitHub branch and Pull Request workflow.

### Out of Scope

- Real online ordering system.
- Payment integration.
- Backend API.
- Database.
- Authentication.
- Admin dashboard.
- CMS or menu editor.
- Real Google Maps API integration.
- Customer accounts.
- Delivery tracking.

## Success Criteria

1. The live Vercel site opens without errors.
2. The page contains Hero, Menu, Location, and Contact / CTA sections.
3. The Menu section has at least 8 items with realistic descriptions and prices.
4. The page is visually polished and looks like a legitimate ramen shop.
5. The page is responsive on mobile viewport widths.
6. The GitHub workflow includes `feat/landing-page` and a documented Pull Request.
7. The final submission includes live URL, mobile screenshot, and 3–5 sentence reflection.
